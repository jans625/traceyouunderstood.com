03 · Before you send to press

Two things that matter

Outline the type. The lockup files contain live text set in Inter Light 300. Open the file in Illustrator and choose Type > Create Outlines, or in Inkscape choose Path > Object to Path, then save. Without this step a press without Inter installed will substitute another font and the wordmark will be wrong. The mark-only files contain no type and need nothing done to them.
SVG is an RGB format. These files carry the correct artwork and geometry, but colour must be assigned in your layout application using the CMYK values above, and the final artwork supplied as PDF, EPS or AI. Ask your printer which they prefer.
